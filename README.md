# آرشیو فیلم (Movie Archive)

اپلیکیشن Next.js برای مشاهده‌ی آرشیو شخصی فیلم‌ها از دیتابیس MySQL. رابط کاربری فارسی، راست‌به‌چپ، و تم تیره (dark mode).

## پیش‌نیازها

- Node.js نسخه ۱۸ به بالا (ترجیحاً ۲۰+)
- MySQL Server در حال اجرا روی ویندوز، با دیتابیس `movies` ایمپورت‌شده (همان دامپی که دارید)

## راه‌اندازی روی ویندوز

1. دیتابیس را ایمپورت کنید (اگر قبلاً نکرده‌اید):
   ```
   mysql -u root -p movies < movies_dump.sql
   ```
   (اگر دیتابیس `movies` وجود ندارد، اول با `CREATE DATABASE movies;` بسازیدش)

2. وارد پوشه‌ی پروژه شوید و پکیج‌ها را نصب کنید:
   ```
   cd movie-archive
   npm install
   ```

3. فایل `.env.local` را باز کنید و اطلاعات اتصال دیتابیس خودتان را وارد کنید:
   ```
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=رمز_عبور_شما
   DB_NAME=movies
   ```

4. سرور توسعه را اجرا کنید:
   ```
   npm run dev
   ```

5. مرورگر را باز کنید: [http://localhost:3000](http://localhost:3000)

در بالای صفحه‌ی اصلی، یک نوار وضعیت سبز یا قرمز نشان می‌دهد که اتصال دیتابیس موفق بوده یا نه، و تعداد فیلم‌های دارای اطلاعات را نمایش می‌دهد.

## ساختار پروژه

- `src/lib/db.ts` — اتصال (connection pool) به MySQL
- `src/lib/movies.ts` — توابع گرفتن داده از دیتابیس (لیست فیلم‌ها، جزئیات، نقد)
- `src/lib/mappers.ts` — تبدیل داده‌ی خام دیتابیس به فرمت مناسب UI (از جمله ساخت آدرس تصاویر TMDB)
- `src/lib/types.ts` — تایپ‌های TypeScript
- `src/components/` — کامپوننت‌های رابط کاربری (کارت فیلم، گرید، جستجو، صفحه‌بندی، نمایش نقد)
- `src/app/page.tsx` — صفحه‌ی اصلی (لیست + جستجو + صفحه‌بندی)
- `src/app/movies/[id]/page.tsx` — صفحه‌ی جزئیات یک فیلم

## نکات فنی

- تصاویر پوستر/بک‌دراپ مستقیماً از TMDB (`image.tmdb.org`) لود می‌شوند؛ فقط مسیر ذخیره‌شده در دیتابیس (مثل `/zMkD6FVikyPNnigoupO7vD5ti9p.jpg`) به آدرس کامل تبدیل می‌شود.
- ردیف‌هایی که `title` آن‌ها `NULL` است (فقط `id` دارند) از لیست و جستجو حذف می‌شوند.
- ستون `reviews.review` یک رشته‌ی JSON است که در صفحه‌ی جزئیات فیلم پارس و به‌صورت خوانا (بدون اسپویل / با اسپویل) نمایش داده می‌شود.
- فونت فارسی: Vazirmatn (از Google Fonts، نیاز به اینترنت در زمان build/dev دارد).

## مرحله بعد (پیشنهادی)

این نسخه فاز اول است: اتصال دیتابیس + نمایش لیست/جزئیات فیلم‌ها. در صورت تمایل می‌توان فیلتر بر اساس ژانر، مرتب‌سازی، صفحه‌ی نقدهای برجسته، و غیره اضافه کرد.
